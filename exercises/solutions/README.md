# Exercise Solutions

Worked answers to each exercise's **Analysis Questions** plus the **expected
observations** in the Spark UI. Attempt the exercise first — reading these before
trying defeats the purpose.

Solutions are grouped by track (matching the `exercises/` subfolders):

- [Fundamentals (Days 1-7)](solutions-fundamentals.md)
- [Performance Tuning (Days 8-14)](solutions-performance-tuning.md)
- [Troubleshooting (Days 15-21)](solutions-troubleshooting.md)
- [Advanced (Days 22-28)](solutions-advanced.md)
- [Streaming (Days 30-31)](solutions-streaming.md)
- [Production (Days 29, 32-40)](solutions-production.md)

> Timing-based questions are only meaningful at `--scale medium`/`large` or on a real
> cluster. On tiny local data, judge by **plans** (`explain()`) and **UI metrics**, not
> wall-clock seconds — the solutions note which is which.
