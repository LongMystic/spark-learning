# Spark + Iceberg Integration

## 🎯 Overview

Master Spark integration with Apache Iceberg for advanced table management and optimization in your on-premise data lake.

## 📚 Topics Covered

1. **Iceberg Fundamentals**
   - Table format overview
   - File layout
   - Metadata management
   - Schema evolution

2. **Spark-Iceberg Integration**
   - Reading Iceberg tables
   - Writing to Iceberg
   - SQL operations
   - DDL operations

3. **Table Optimization**
   - Partition evolution
   - File compaction
   - Expire snapshots
   - Metadata optimization

4. **Query Optimization**
   - Partition pruning
   - File pruning
   - Metadata filtering
   - Statistics utilization

5. **Time Travel & Versioning**
   - Snapshot management
   - Historical queries
   - Rollback operations
   - Audit trails

6. **Advanced Features**
   - Hidden partitioning
   - Partition transforms
   - Upsert patterns
   - Merge operations

7. **Performance Tuning**
   - Compaction strategies
   - Parallelism tuning
   - Metadata caching
   - File organization
